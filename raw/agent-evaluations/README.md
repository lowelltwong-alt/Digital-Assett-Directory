# Raw Subagent Evaluations

Immutable role-profile revisions, execution attempts, evaluations, and unrated inventory
records are written here through `asset-dir subagents ingest` when DAD is using the legacy
data root. With an initialized `DAD_DATA_ROOT`, the same logical path resolves there.

Runtime JSONL is ignored by Git. Reusable example packets belong under
`examples/subagent-evaluations/`.
