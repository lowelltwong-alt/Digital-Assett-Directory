# Common AI Coding Preflight

## Core rule

Clear boundaries, clear names, clear contracts, clear tests, clear verification.

## Checklist

- [ ] Goal is explicit.
- [ ] Context files are identified.
- [ ] Constraints are explicit.
- [ ] Done-when criteria are explicit.
- [ ] Public entry point is identified.
- [ ] Private/internal helpers are identified.
- [ ] Inputs and outputs are typed or clearly described.
- [ ] Side effects are identified.
- [ ] Existing tests are identified.
- [ ] Missing tests are noted.
- [ ] Verification command is known.
- [ ] Diff can be reviewed in small chunks.
