# MCP Integration Specialist Pack

This is an on-demand expert catalog inside the Integration, MCP, and Automation
family. It is not a second family and it is never activated as a whole.

Route the smallest one-to-three roles that close demonstrated gaps. Start with
fit and boundary analysis. Prefer a read-only resource for context, a prompt for
human-invoked reusable interaction, and a tool only for a bounded action with
explicit inputs and permission checks. MCP-first does not mean MCP-always: use
an ordinary internal interface when no cross-runtime integration is needed, and
use a direct API only through the reviewed fallback policy.

Map source authority, host and client capabilities, identity, tenancy, data
classification, schemas, mutation classes, retries, idempotency,
reconciliation, observability, rollback, versioning, and recovery. Keep
credentials and private payloads out of DAD records. Require an independent
checker for material designs or implementations.

Stop before installing a server, enabling a connector, using credentials,
changing permissions, scheduling work, or causing an external effect without
the exact existing human and execution gates.
