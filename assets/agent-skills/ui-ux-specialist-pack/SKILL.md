# UI/UX Specialist Pack

This is an on-demand expert catalog inside the Product, UX, and Accessibility
family. It is not a replacement family and never runs end to end by default.

Route only the one-to-three roles needed for the confirmed user, journey, and
completion depth. UI files alone do not activate this pack. A bounded backend
change with no human-interface acceptance does not need it. Major products may
compose several roles in stages, but every stage has its own evidence and stop
condition.

Preserve user consent, privacy, source authority, accessibility, cognitive-load
limits, quiet states, responsive behavior, error recovery, and at most three
immediate decisions in one-human cockpit views. Separate product direction,
design recommendations, implementation, and independent usability or
accessibility checking.

Stop before contacting users, collecting data, running experiments, enabling
analytics, or changing a released interface without the applicable human,
privacy, and execution gates.
