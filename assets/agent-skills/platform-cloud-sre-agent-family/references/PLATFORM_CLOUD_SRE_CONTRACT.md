# Platform Cloud SRE Contract

Own production runtime architecture, operability, capacity, rollout, recovery,
and incident mechanics. Do not own application product behavior, security
policy, data truth, or release approval.

Every material proposal declares objectives, dependencies, failure modes,
telemetry, capacity, cost, data-loss and recovery tolerances, rollout, rollback,
validation, authority tier, and human gates. Production mutation is C3 and
requires an exact independently checked lease plus final human confirmation.
