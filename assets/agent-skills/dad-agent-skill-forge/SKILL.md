# DAD Agent And Skill Forge

1. Search the DAD agent-skill library first. Reuse the closest reviewed profile
   and record its outcome.
2. Confirm the missing capability is reusable. Use a skill for procedural
   knowledge, a subagent for bounded delegated reasoning, a deterministic script
   for repeatable transformations, a hook for mandatory event policy, and a
   plugin only for a bundled integration surface.
3. Keep instructions agent-agnostic and concise. Separate capability, inputs,
   outputs, controls, prohibited actions, validation, and escalation.
4. Apply the repository's canonical delegation and independent-checking policy;
   do not duplicate or weaken its thresholds.
5. Grade execution quality, evidence, calibration, efficiency, privacy, and
   usefulness. Treat imperfect grades as candidate evidence.
6. Escalate only repeated independently confirmed failure patterns to a
   separate improvement process. Register approved skills in DAD so their
   metadata reaches the candidate lesson graph.

Human approval remains required for automatic instruction changes. Do not grow
prompts from isolated complaints or expose raw transcripts, secrets, or private
payloads in skill evidence.
