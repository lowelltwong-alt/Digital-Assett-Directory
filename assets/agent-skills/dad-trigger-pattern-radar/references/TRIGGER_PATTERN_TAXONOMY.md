# Trigger Pattern Taxonomy

Use these families as search seeds, not a closed ontology.

| Family | Positive signals | Suppressor or boundary |
| --- | --- | --- |
| Neglected work | dirty/ahead branch, activity elsewhere, owner or next action gap | quiet state, clean merge, age alone |
| Resume opportunity | verified identity and prior next action/evidence | identity or coverage unavailable |
| New-idea relation | shared goals, artifacts, decisions, dependencies | superficial token overlap; never merge |
| Branch/workstream mismatch | independent outcomes share a branch | cohesive refactor subdivisions |
| WIP overload | execution leases exceed capacity | explicit expiring incident mode |
| Board-state drift | observed facts disagree with projection | refresh incomplete coverage first |
| Missing next action | active evidence but no bounded step | intentional wait or incubation |
| Dependency discovery | interfaces, artifacts, blockers, ordered gates | similar filenames or co-change alone |
| Unlock frontier | reviewed high-fan-out prerequisite or acceptance gate | centrality or proposed edge alone |
| Bottleneck recurrence | repeated waiting, queue growth, failed handoffs | one slow run or intentional wait |
| Validation gap | material change lacks check or evidence | explicit accepted not-run risk |
| Repeated manual sequence | stable repeated inputs, steps, and outputs | judgment-heavy or unsafe side effects |
| Learning-loop gap | surprise/failure lacks response or validation | no material learning event |
| Asset/harness opportunity | reusable code, schema, prompt, or review recurs | one-off/private/provenance unknown |
| Handoff stall | completed output lacks consumer or next action | deliberate named-human pause |
| Cost mismatch | costly model on routine work or cheap model repeatedly fails | one incomparable attempt |
| Long-run optimization | measured >=60s or predicted >=120s | service wait or no local hotspot |
| Context-loss risk | decisions remain only in chat/temp output | raw transcript or hidden reasoning capture |
| Sovereignty transition | child nears delivery and authority must change | no approved scope or recipient |
| Reminder fatigue | repeated dismissals or unchanged evidence | materially new evidence may wake |
| Trigger miss | a useful action should have fired but did not | anecdote is not reusable proof |
| Trigger false positive | action was irrelevant, harmful, or premature | preserve counterexample; never hide it |

For novel candidates, ask whether the reusable asset is the trigger, workflow,
validator, suppressor, or their composition.
