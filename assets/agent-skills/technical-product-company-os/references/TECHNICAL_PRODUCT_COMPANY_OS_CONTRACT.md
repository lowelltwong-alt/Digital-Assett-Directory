# Technical Product Company OS Contract

## Control planes

1. Keep source-owned, versioned descriptors authoritative.
2. Build a fingerprinted, rebuildable discovery index and typed candidate graph.
3. Preserve workflow definitions separately from append-only route and run events.
4. Route improvement through deduplicated evidence, independent checking,
   held-out trials, rollback, and named-human adoption.

## Decision rights

Use `observe`, `retrieve`, `recommend`, `draft`, `validate`, `execute`, and
`prohibited`. Apply consequence tiers C0 through C4. C0 is bounded observation;
C1 is a reversible local draft; C2 is a material governed change; C3 has an
external or production effect; C4 is prohibited. Model strength, graph position,
frequency, and prior approval never create authority.

For C2 require named scope, independent validation, tests, and rollback. For C3
also require an exact preview, verified time-bounded lease, and separate final
human confirmation. Prohibit final legal conclusions, unbounded autonomous
self-modification, authority bypass, secret movement, hidden persistent capture,
and irreversible destructive action.

## Retrieval

Apply hard eligibility first, then exact aliases, lexical retrieval, optional
semantic candidates, prior validated workflows, dependency expansion, and
bounded reranking. Benchmark required recall, false activation, missing
validators, smallest-set accuracy, human overrides, task pass rate, cost, and
latency on held-out real, vague, negative, and multi-capability cases.

## Telemetry

Use CloudEvents-style stable envelopes and OpenLineage-style definition/run
separation. `last_used_at` equals last linked execution, never selection.
Deduplicate route retries by semantic task and router revision; deduplicate run
events by source and event ID. Exclude synthetic evidence from operational
aggregates. Append corrections rather than rewriting history.

## Operator

Show at most three immediate decisions. Batch the rest. Support defer, snooze,
quiet mode, next review, compact resume, drill-down evidence, and one-click copy
of a bounded execution packet without embedding an execution control.
