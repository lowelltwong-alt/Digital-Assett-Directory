# Manual Runbook

1. Identify the claim the change is making.
2. Look for false confidence, missing tests, stale generated output, and unclear authority.
3. Separate critical blockers from style or preference findings.
4. Give concrete file paths and a test or proof for each serious finding.
5. Record reusable failure patterns in postflight or candidate mail.

This runbook supports adversarial review; findings remain recommendations until fixed and verified.
