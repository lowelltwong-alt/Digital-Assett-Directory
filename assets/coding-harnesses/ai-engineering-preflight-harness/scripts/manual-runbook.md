# Manual Runbook

1. Run DAD preflight before material work.
2. Read recommended assets, stop conditions, and review lanes.
3. Acknowledge required learning rules through midflight before continuing.
4. Record commands, tests, assumptions, unknowns, and review-lane status in postflight.
5. Route reusable lessons or asset feedback back to DAD as candidate evidence.

This runbook is model-agnostic and does not override local repo authority.
