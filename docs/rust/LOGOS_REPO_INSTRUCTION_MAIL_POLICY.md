# Logos Repo Instruction Mail Policy

Repos with `logos` anywhere in their name receive Rust instruction packets only.
DAD must not force Rust scaffolds into those repos.

Instruction packets may say:

- DAD implemented Rust first and captured lessons.
- The Logos repo should implement Rust under its own governance if useful.
- The Logos repo owns any Rust files it creates.
- Rust should stay in deterministic leaf roles such as scanners, indexers,
  manifest validators, JSONL validators, source/hash checks, and marker tooling.

Rust in Logos must not own doctrine, canon authority, theological judgment,
review promotion, route behavior, governance authority, or cross-repo authority
changes.
