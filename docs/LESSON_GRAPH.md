# Lesson Graph

DAD's lesson graph is a rebuildable candidate graph compiled from raw lessons,
reviewed registries, and usage ledgers. The graph is safe to delete and rebuild;
raw records and registries remain the source of truth.

## Edge Classes

Graph edges come from `registry/graph-edge-registry.json`.

- `join` edges are deterministic joins over explicit records, such as a lesson's
  `repository` field or a usage ledger row.
- `inference` edges are hypotheses generated by a named method. They must carry a
  method version and never promote themselves.

Every edge remains candidate evidence until a local review process decides how to
use it.

## Generated Files

- `processed/learning/lesson-graph.json` is the compiled graph.
- `processed/learning/lesson-graph-manifest.json` records input hashes, edge
  definitions present in the build, counts, and coverage gaps.

Validation checks that generated edge types are registered, edge bases are allowed,
inference edges have method versions, and the manifest still matches current inputs.

## Query Path

Start with:

```text
asset-dir lesson graph
```

Then inspect pattern gaps and unmatched asset refs in the command summary. These are
curation queues, not proof that DAD should invent a new pattern or asset.
